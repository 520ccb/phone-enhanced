# Phone Enhanced - 酒馆助手手机增强插件

为 [Abstract 外置手机](https://phone-ctn.pages.dev/index.js) 角色卡插件提供本地文件上传与壁纸增强功能。

## 功能

- **表情包本地上传**：在添加表情包对话框中点击「本地上传图片」，选择本地图片后自动填入链接，填写名称（即 AI 识别描述）即可。手机插件会自动将名称列表注入提示词。
- **角色图片本地上传**：在添加角色图片对话框中同样支持本地上传，名称用于消息引用识别。
- **头像 / 背景 / 手机屏幕背景本地上传**：图片选择弹窗和添加到库弹窗均新增文件夹按钮，可直接从本地选择图片。
- **首页滑动看壁纸**：在手机首页向左滑动，进入无 APP 的壁纸浏览页；向右滑动返回。
- **壁纸管理**：壁纸页右上角点击图片图标打开管理面板，支持从本地添加多张壁纸、点击切换、删除壁纸。壁纸数据保存在角色变量中。

## 安装

在酒馆助手脚本中添加：

```js
import 'https://cdn.jsdelivr.net/gh/520ccb/phone-enhanced@main/index.js';
```

需配合 Abstract 外置手机插件使用。

## 技术说明

- 图片自动压缩（表情包 512px、头像背景 800px、壁纸 1080px），GIF 保留动画。
- 壁纸存储于角色变量 `phone_enhanced_wallpapers` / `phone_enhanced_wallpaper_idx`。
- 兼容触摸滑动与鼠标拖拽。
